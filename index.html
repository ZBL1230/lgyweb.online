PROJECT FILE — 01 2026 · 省赛三等奖

万花筒 Kaleidoscope

从一截亚克力圆筒，到一台可以平视观看的光学玩具。半个学期，一边做一边改。指导：王老师。

时间 / Time2026 · 半个学期
角色 / Role建模 · 制作 · 调试
成果 / Result省赛三等奖
涉及 / Skills3D 打印 · 光学 · 电路

项目由来

这个项目前后花了半个学期。我拿到手时，它只是一个亚克力圆柱体，里面装着三片镜子，其余结构大多没做完——严格说是个半成品。接下来的时间，我一边补结构一边调整，打磨、试装、再打磨；王老师在旁边给了很多指导。最后成品参加省赛，拿到三等奖。

底座：把误差一点点磨掉

底座是第一个难关。我在建模软件里画好模型，但一开始没经验，内径算得不准，打印出来和圆筒根本套不上。只能拿砂纸磨，磨完试装，不行再磨，反复很多次，才做到松紧刚好。

后来我把底座改成抽屉式：抽屉里放彩片，推到底时磁感开关接通，内部灯亮，彩片被照亮，反射出的图案也更清楚。抽屉尺寸同样改了好几轮——太松会滑出来，太紧又推不动。抽出抽屉就能换彩片，花纹也跟着变。

镜体：让三面镜子重新对齐

检查镜体时，我发现三片镜子已经脱落移位，歪着，根本无法成像。我先用透明胶带把三面镜子按等边三角形对齐，缠几圈临时固定，反复比对缝隙，确认角度没有歪。位置对了，再沿拼接缝打热熔胶加固；等胶冷却，镜组才算真正固定。最后把整套镜子顺着筒壁推到筒身中段，推送时格外小心，避免碰歪镜面。

观察镜：把视线折过来

普通万花筒要低头凑近筒口看，久了脖子发酸。我参考潜望镜的原理，设计了一个侧向观察镜：在观察筒里加一片反射镜，让竖直向上的光转成水平方向，眼睛对着侧面就能看到图案。配套的顶盖里，镜片装在圆弧轨道上，手动拨动就能改变倾角，用来微调光路，直到图案最清晰。

组装：在轨道上找到那一格

零件齐了，开始总装。彩片放进抽屉，推入底座，磁感开关一次成功：推到位灯亮，抽出灯灭。再依次装上镜筒、观察镜和顶盖。第一次装好时几乎看不到图案，我沿着圆弧轨道一点点拨镜片，调一次看一次，来回很多次，同时把抽屉里的彩片摆正，才终于看到清晰的对称花纹。之后换了几款彩片测试：转动底座，花纹不断变化，但始终对称；开灯之后，成像更清楚，颜色也更鲜亮。

收获：走弯路也算数

整个过程半个学期：建模尺寸改到返工，粘镜子因为角度不对撕掉重来，打磨调试更是家常便饭。很多操作我都是第一次做，不熟练，进度也慢。好在王老师一直给建议，帮我优化结构，成品最后顺利参赛，拿到三等奖。这次项目让我真正理解了光的反射和多次成像，也练了三维建模、手工粘接和调试。过程挺折腾，弯路不少，但做出能用的东西、还拿了奖，收获很大。
